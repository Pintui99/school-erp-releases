## System Requirements

- **Operating System**: Windows 10 (version 1809 or higher) or Windows 11 (64-bit)
- **Architecture**: x64
- **Processor**: Intel / AMD Dual Core 2.0 GHz or faster
- **Memory (RAM)**: 4 GB minimum (8 GB recommended)
- **Disk Space**: 500 MB free space
- **Runtime**: Self-contained (No separate .NET runtime installation required)

---

## Installation Instructions

1. Download **`Setup.exe`** from the link above.
2. Double-click **`Setup.exe`** to begin installation.
3. The installer sets up the application and places a shortcut on your Desktop and Start Menu.
4. Launch **Parth School ERP** from your Desktop shortcut.

### First-Time Login
- **Default Username**: `admin`
- **Default Password**: `Admin@123`
*(You will be required to set a strong, private password on your first sign-in).*

## Automatic Updates

Parth School ERP includes an automated in-app update channel:
1. When a new version is published here, the ERP notifies you automatically.
2. You can also manually check for updates at any time by opening **Settings** > **About & Updates** and clicking **Check for Updates**.
3. Updates download quickly and apply seamlessly upon restart.

---

## Data Safety Guarantee

All school data (students, teachers, fees, exam records, photos, settings, and backups) is stored separately in `%AppData%\SchoolERP`. 

**Installing updates or reinstalling the application will NEVER delete or modify your school records.**
